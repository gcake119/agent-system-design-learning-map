## Persistent learning surface

節點有實際狀態；以文字標示等待、異常、未使用、未知與可接受，不能只靠顏色。有限引數重算純模型；選節點聚焦它的輸入／輸出／證據。關係以有標籤的箭頭清單呈現，快取 hit／miss、讀取分支與回應方向必須正確，窄畫面不能藏掉連線含義。

必要 prose 持續可讀，不把每個節點的詞彙字典塞進圖。選節點是 evidence inspection，會改變可比較的證據範圍，並非點按揭露連續段落。

## Learner response／comparison

每段顯示本段主要問題、觀察目標與一個自由說明欄位。筆記僅存目前瀏覽器；不是答案評分。可儲存基準，再改一個引數比較關鍵數值差異；重設目前實驗清除模型／比較基準／本題筆記，保留造訪紀錄與其他章節。

## Final Integrated Transfer

同一案件檔案架構，五個中性現象：查詢延遲、結果未確認、檔案等待、通知等待、另一頁舊值。只給 requirement／workload／state／evidence，不標章節。跨事故保留 learner 的設計選擇；新事故改變負載與觀察條件。可回上一事故、下一事故、重開整合練習。以自己的說明與驗證方案收束，不提供通關分數。

## QA observable contracts

Given 固定 workload，When 開啟讀取副本，Then 來源讀取量按 miss 比例降低，命中分支不再到來源。
Given 副本未更新，When 降低來源負載，Then 舊版本仍可見，不冒充正確性改善。
Given 60 秒空佇列視窗，When 增加工作者，Then 處理能力上升、未完成工作下降；worker 故障時不憑空完成。
Given 已確認主資料 v3，When 觀察時間到傳遞延遲，Then 選定副本追到 v3；是否可接受仍依時效要求。
Given 同一通知逾時，When 切換證據，Then 外部結果維持未知，直到另外查證。
Given 教學實驗已修改，When 進下一節、回退或 reload，Then 狀態可恢復；重設只作用於當前實驗。
Given 進入 Transfer，When 讀題及操作，Then domain、成功要求與證據不同，且沒有答案選項。

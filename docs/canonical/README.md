## Content Review 規則

每個單元 brief 至少包含：

- central question；
- learning objectives；
- core claims；
- reasoning / mechanism；
- terminology；
- prerequisites；
- 經典主案例與對比案例；
- misconceptions / boundary cases；
- transfer target；
- claim-level sources；
- 尚待核實的內容。

來源層級沿用 `docs/source-strategy.md`。Canonical Content 中的教學簡化必須保持機制與適用條件；不能把某個 pattern、資料庫或雲端產品的行為泛化成所有系統的保證。

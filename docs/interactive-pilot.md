# Agent Loop 互動情境試作

## 本輪目的

驗證「地圖 → 操作情境 → 觀察連動結果 → 理解題與紀錄 → 回到地圖」的完整體驗。保留既有視覺方向，先不擴展其他章節。其他章節只提供標示清楚的簡報預覽。

## 情境契約

使用者要確認案件 #1024 目前附件是否齊全，權限只有讀取。資料來源可選即時工具／昨日快取；工具可正常回應、首次逾時或持續逾時。設定最多 1–4 次工具呼叫、是否重試及是否交給人工。

每步以同一執行狀態衍生階段、工具結果、案件資料、輪次、呼叫計數和軌跡。逾時不是空的成功結果；昨日快取不能直接完成即時查詢；所有路徑有限終止。不模擬任何真實模型內部思考，也不呼叫外部案件服務。

「情境已通過」要求安全完成／人工交接，且選對對應結果的理解題。停止但未交接的練習可以閱讀回饋，但不能記為通過。紀錄只表達此情境的結果，不是一般能力認證。

## 驗收腳本

1. 首頁是地圖而非 slide。點其他節點能看到學習目標及「互動尚未製作」說明。
2. Agent Loop → 進入情境 → 開始：設定鎖定，逐步前進後計數與軌跡同步更新。
3. 預設首次逾時、最多 3 次、允許重試：第 2 次查詢成功，回覆後停止。
4. 持續逾時、最多 1 次：不得再呼叫工具，開啟人工出口時交接。
5. 持續逾時、停用人工出口：顯示未解決，不允許保存為通過。
6. 昨日快取：0 次工具呼叫，顯示過時資料並禁止據此完成查詢。
7. 答錯理解題有解釋；答對安全終點可保存。回地圖顯示情境通過及實驗紀錄。
8. 重新整理地圖後已保存紀錄存在。瀏覽其他章節不會增加已完成數。
9. 學習介面與 `/slides/` 可雙向切換，`/slides/3` 重新整理可載入。
10. 檢查窄螢幕可垂直捲動，控制可觸及、不水平溢出；鍵盤可操作表單和按鈕。

## 限制

- 本輪只實作一個完整情境；其他章節仍是簡報。
- 純前端確定性教學模擬，無登入、後端、真實 Agent API。
- 正在執行的暫存狀態重新整理即重設；已保存成果最多保留最近 5 筆。
- 互動介面與簡報共用章節資料，但不是自動把投影片轉成互動課程。
- 真機、跨瀏覽器與完整無障礙稽核需另行驗證。

# 課程圖解與動畫

參考使用者提供的《Bytebytego Big Archive System Design 2025》PDF 第 12（gRPC）、42（AI Agent）、102（RAG）頁的視覺組織：具象元件圖示、短標籤、責任分區、編號與定向連線。所有圖形與案件內容重新繪製，沒有嵌入原書圖片或商標。

課程使用淺底版本。模型為淡紫，資料來源為淡藍，工具為青綠，信箱／交接為淡黃，驗證為淺綠。顏色輔助辨識，同時保留圖示、文字與方向。

- 基礎情境、方案比較、七單元動畫、設計工作台共用 `SystemDiagram.vue`。
- `diagram-layout.mjs` 管理分支、循環、回應與刷新連線；純概念對照不強行加上箭頭。
- 資料包沿連線移動；回應遺失時停在中點，顯示中斷與已提交效果提示。
- 狀態更新、重播、回退與原本操作共用；關閉動態及 reduced-motion 保留完整結果。
- SVG 可縮放，窄螢幕提供圖內水平捲動，完整文字另可展開；每張圖使用獨立的標記與可存取描述。

圖解示意的是教學模型，不代表實際產品部署拓撲。
